# 盟约干员图鉴 · Covenant Atlas

《明日方舟》卫戍协议：规程 —— 盟约干员图鉴的静态网页版。

- 收录 141 名干员、10 个核心盟约与 16 个附加盟约
- 支持按盟约 / 等阶 / 特质类型组合筛选，关键词搜索
- 支持普通特质与精锐特质对照、按特质类型着色、深浅色主题
